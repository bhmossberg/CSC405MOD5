# Program 3.1 — Building Transformation Matrices in GLSL

Section 3.10 of Gordon & Clevenger (2021). These five GLSL functions are the entire program listing; the official companion zip has no Chapter 3 Java project.

`transforms.glsl` was transcribed from the book listing. Include or paste the functions into a vertex shader when you want to build transforms in GLSL rather than with JOML on the Java side.
